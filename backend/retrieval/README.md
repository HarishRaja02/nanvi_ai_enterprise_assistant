# Knowledge Retrieval

Canonical documentation: [`../../docs/12-rag-retrieval.md`](../../docs/12-rag-retrieval.md).

Implemented: bounded chunking, in-memory keyword retrieval, vector-store interface plus in-memory vector implementation, hybrid fusion, authorization before reranking, source metadata and vector-failure keyword fallback.

Partial: no durable vector backend, production embedding provider, ingestion scheduler or semantic reranker.
