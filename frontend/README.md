# Nanvi React Frontend

Canonical documentation: [`../docs/05-frontend-structure.md`](../docs/05-frontend-structure.md) and [`../docs/06-authentication.md`](../docs/06-authentication.md).

Implemented: React + TypeScript + Vite UI, typed API client, chat/history/source/report-download flows, loading/error/empty states, responsive styling and role-aware presentation.

Partial: production browser SSO callback/session flow, file upload UI, streaming UI and capability-specific data workspaces are not implemented. Frontend role visibility is never the authorization boundary.
